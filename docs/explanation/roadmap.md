# Roadmap

## Shipping today

`compile`, `seal`, and `preflight`. Each one is documented on the [CLI reference](/reference/cli-commands/) and run end to end in [Run the three commands](/how-to/run-the-three-commands/).

## Next

Scoring. Nothing in the current release computes contract strength, defect detection, or any other score, and exit codes 1 and 2 stay unreachable until it lands.

No date is set.
