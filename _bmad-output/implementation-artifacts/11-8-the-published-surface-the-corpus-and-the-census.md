## Intent

**Problem:** Four stories changed the language and every enumeration a generator owns still counts to the old total. `corpus/dev/` ships 21 contracts (`corpus/dev/index.json` carries 24 entries: 22 of kind `contract`, one `sealed-evaluator-brief`, one `readme`), and 18 of the 21 declare an `api` interface, 2 declare `cli`, and `no-operation-inventory.json` declares none. Not one describes a tool server, so the kind this epic opened has no published example and nothing has ever run `score` over an `mcp` sealed run record. `tests/schemas/published-census.ts` pins six constants over the published schemas; Stories 11.4 and 11.6 moved four of them and this story is where all six are read back against the tree. `scripts/dev-corpus-target.ts` hand-writes six spelled-out numerals across four lines, `:65`, `:108`, `:114` twice and `:115` twice, and this story's diff falsifies four of them at their source. Six sentences under `docs/` and `README.md` hand-write the same corpus count and `scripts/check-docs.mjs:9-15` still does not scan `docs/`, so nothing gates them.

**Approach:** Promote Story 11.4's `mcp` fixture into `DEV_CORPUS_CONTRACTS`, run every generator, and take that exemplar end to end through `compile`, `seal`, `preflight` and `score` so the kind's last unrun stage has a run behind it. The pinned numbers are read against the post-11.6 state: the corpus manifest and the corpus README are the only generated bytes this story moves, and the six census constants carry the values Stories 11.4 and 11.6 left, each re-read and recorded here with the story that moved it. Then correct every hand-written count this story falsifies, in the same diff, at its source, and ship the script that gates fourteen of them so the next epic finds none of them by grep.

## Boundaries & Constraints

**Always:**

- Regenerate through the `generate:` scripts. A generated file is never hand-edited. `corpus/dev/README.md`, `corpus/dev/index.json`, `schemas/*.schema.json`, `docs/ad21-*.generated.md`, `docs/ad31-*.generated.md`, `docs/ad33-*.generated.md`, the worked chain's five files, and `_bmad-output/shareable/*.html` each come from their own generator and their own `check:` script proves it.
- Prose edits land at the template, so `corpus/dev/README.md`'s text is edited in `scripts/dev-corpus-target.ts` and reaches disk through `npm run generate:dev-corpus`.
- Every pinned number is read from the failure that names it, and a number this story leaves alone is recorded with the value it holds and the story that put it there. `published-census.ts:8-13` records why the six stay pinned integers: a floor cannot catch a narrowed walk, and dropping `propertyNames` from the occurrence descent silently removes 28 occurrences while every other assertion passes.
- `check:boundary` scans `src/`, `schemas/`, `corpus/`, and three `package.json` fields against twelve forbidden patterns (`BOUNDARY_PATTERNS`, `scripts/package-boundary.ts:56-105`), and `story`, `epic`, `AC n`, task numbers and story-local decision numbers are five of them. The corpus README is generated into `corpus/`, so its template text in `scripts/dev-corpus-target.ts` is in scope.
- Documentation moves in the same diff as the change that falsifies it. Every hand-written count the corpus and the census falsify is corrected here, with the current sentence, its line, and its replacement named in the Code Map.
- Every `.describe()`, JSDoc and comment this story writes gets the voice pass while it is written. No comment runs longer than the declaration it documents. After editing, grep the edited files for `, not `, `rather than`, `instead of`, `as opposed to`, `, never `, `no longer` and keep only the hits where both halves carry a fact.
- Updated is the floor. Text this change makes redundant is cut in the same pass.
- A caller-facing change is disclosed in `CHANGELOG.md` under `[Unreleased]` in the same diff, per NFR8 (`epics.md:54`) and the file's own header at `:7-9`. Nothing below `[Unreleased]` is touched: `npm run release:prepare` (`package.json:111`) is what moves a section into a dated heading.
- The learning-path step is written after the peer review's findings are addressed and before the human reviews locally, following `_bmad-output/project-knowledge/learning-path-template.md`.

**Ask First:**

- Any `src/` behaviour change. Every behaviour this story regenerates over shipped in Stories 11.3 through 11.7, and a behaviour found missing here is a finding against one of them.
- Any `schemaVersion` move. Story 11.4 owns the eval contract's breaking bump and the probe's first; Story 11.6 owns the probe's second and the sealed run record's. This story restates all four and moves none.
- A second compile-and-seal example. `EXAMPLE_SEED_ID = 'satisfied-declarations'` (`scripts/dev-corpus-target.ts:69`) is what `scripts/check-doc-invocations.mjs` replays every documented command against, so a second example doubles that surface.

**Never:**

- No hand-edit of a generated file. A wrong byte in `corpus/dev/README.md` is repaired in `scripts/dev-corpus-target.ts` and regenerated.
- No number asserted from memory. Every count in this story's diff is read off the artifact or off the failing assertion at the time it is written.
- No spine edit, no spine revision, and no new ADR. Story 11.5 owns `ARCHITECTURE-SPINE.md:232`, `:288` and `:656`, because opening the kind is what falsifies all three. This story reads them and asserts they already say what the shipped behaviour does.

The index block at `docs/index.md:70-84`, the What Ships tool-use section, the tool-use guide rewrite and its `:242` are Story 11.9's; `docs/how-to/author-behavioral-contracts.md:148`'s observation-`kind` sentence is Story 11.13's; `docs/reference/glossary.md:91` and `docs/explanation/what-ships.md:18` are Story 11.5's; `docs/how-to/evaluate-ai-feature-behavior.md:14` is Story 11.4's. ## Design Notes

The organising idea is that a number nobody generates is a number that goes stale, and this repository has two answers to that. Where a generator owns the value, the fix is to move the input and rerun the generator, and the `check:` script turns a stale byte into a build failure: that covers `corpus/dev/README.md`, `index.json`, `schemas/*.schema.json` and the three AD tables. Where a human owns the value, the fix is a pinned constant whose failing assertion names which number moved, which is what `published-census.ts:8-17` buys and why its six stay integers.

The third category is the one this story spends most of its diff on: prose that states a number no mechanism reads. Fourteen published numerals and one spine table cell are in that category today, and the AD-5 row at `ARCHITECTURE-SPINE.md:232` shows what it costs, having carried a wrong kind list through a full release. Story 9.5 answered it with story discipline and a Vitest test that never landed, and two epics of drift is the measurement that argues against repeating the answer. So the fourteen counts get the third mechanism this repository already runs eleven of: a script that computes the value from its source, renders it, and fails the build on a mismatch. The spine cell keeps the story-discipline answer under Story 11.5's ownership, with this story's read as the second pair of eyes, because `check:ad5-registry` reads the first column by design and widening it to grade prose is a different check than the one AD-5 needs.
