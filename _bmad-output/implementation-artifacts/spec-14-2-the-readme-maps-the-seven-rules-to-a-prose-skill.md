## Intent

**Problem:** `README.md:104` states the seven authoring rules in terms that read as API checks (body, per record, sibling parameters, state change), so a maintainer of a skill that writes documents has to translate them before knowing which checks to write.

**Approach:** Add one sentence directly after the seven rules that maps them to a prose skill through three checks: exclusion, negative inputs, and reading back the artifact the skill wrote. Rebuild the shareable README export and record the sentence under `CHANGELOG.md` `[Unreleased]` in the same commit.
